# Grok Bug Reporter

Independent companion desk for writing paste-ready bug reports for Grok and every other xAI product and service.

This is **not** an official xAI channel and it does **not** file tickets. It structures a report, checks completeness, and points you to the official Report an issue, billing, or API support path.

## What it covers

- **Grok** — Chat, Imagine, Voice, Grok on X, iOS, Android, Companions
- **Create & Build** — Grok Build, Imagine API, Grok Computer
- **Developers** — API / Grok API, Console, SDKs, grok CLI, xAI status
- **Account** — Billing, SuperGrok, Team / Enterprise
- **More** — Tesla, Grokipedia

Drafts stay in this browser (`localStorage`). Nothing is uploaded.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints. The app is a TanStack Start + Vite site.

```bash
npm test
npm run typecheck
```

## Official submission paths

| Path | Use for |
| --- | --- |
| Report an issue on grok.com | Product bugs (Chat, Imagine, Voice, apps, Build, Tesla, …) |
| `https://grok.com/?_s=billing` | Subscriptions, SuperGrok, receipts |
| `support@x.ai` | API / Console / SDK / grok CLI |

Paste the generated report. Do not send secrets, API keys, or private conversation content.
